A responsive e-commerce product page built with **Tailwind CSS** and **Vanilla JavaScript**

## Features

- **Tailwind-Powered UI**: Pure utility-class styling with zero custom CSS
- **Interactive Components**:
  - Product image gallery with thumbnail navigation
  - Quantity selector with +/- controls
  - Dynamic shopping cart with add/remove functionality
  - Responsive mobile menu
- **Performance**: Lightweight (no jQuery/React overhead)
- **Accessibility**: Semantic HTML with ARIA attributes


## Technologies
| Category        | Technologies Used               |
|-----------------|---------------------------------|
| Core            | HTML5, CSS3, JavaScript (ES6)   |
| CSS Framework   | Tailwind CSS v3.3+              |
| Build Tools     | Tailwind CLI                    |
| Design Assets   | Frontend Mentor design files    |
